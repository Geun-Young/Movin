# Movin — AI 데일리 브리핑 박스

출퇴근 시간에 한 손으로 넘겨보는 카드형 AI 뉴스 브리핑 서비스.
관심 도메인을 고르면 매일 아침 **뉴스 3줄 요약 · 경쟁사 공시 · 업계 영단어**를 카드로 받아본다.

## 현재 상태

**0단계(소스 검증) 완료.** 파이프라인 구현 전 단계.

## 아키텍처

```
Vercel Cron (매일 06:00 KST)
   ├─ RSS 수집          → 기사 제목 + URL
   ├─ Gemini url_context → 기사 본문 읽기 (요청당 20개 제한)
   ├─ Gemini 요약        → 3줄 요약 + 키워드 + 영단어
   ├─ OpenDART API      → 경쟁사 공시 요약
   └─ DB 저장

유저 접속 = DB 읽기만 (AI 호출 0건)
```

**핵심 원칙: 유저 요청 경로에 AI 호출을 두지 않는다.**
비용이 유저 수가 아니라 도메인 수에만 비례하므로, 유저가 늘어도 원가가 늘지 않는다.

## 기술 선택 배경

`google_search`(Grounding) 대신 **`url_context`** 를 쓴다. Grounding은 약관상
Search Suggestions 표시 의무, 결과 수정 금지, 저장 제한(이미 표시한 것 평가용 또는
해당 유저 본인 기록용만), 링크 30일 만료가 걸려 있어 **미리 만들어 여러 유저에게
배포하는 구조와 맞지 않는다.** `url_context`는 이 제약이 없고 호출당 요금도 없다
(토큰만 과금).

## 0단계 검증 결과 (2026-08)

`url_context`가 국내 언론사 본문을 실제로 읽는지 확인한 결과:

| 도메인 | 사용 가능 소스 |
|---|---|
| 금융/핀테크 | 한국경제 금융, 매일경제 경제, 연합뉴스 경제 |
| 이커머스/유통 | 한국경제 IT, 매일경제 기업, 전자신문, 지디넷코리아 |

제외: 아시아경제·벤처스퀘어(`URL_RETRIEVAL_STATUS_ERROR`), 서울경제(RSS 404)

검증 중 확인된 사항:
- `url_context`로 국내 기사 본문 접근·요약이 **정상 작동**한다
- **503(혼잡) 응답이 자주 발생** → 배치에 재시도 로직이 반드시 필요하다.
  재시도 없이 판정하면 멀쩡한 소스를 잘못 제외하게 된다 (실제로 4개 → 7개로 뒤집힘)
- `gemini-2.5-flash`는 신규 사용자에게 폐지됨(404). 현재 `gemini-3.5-flash` 사용

## 실행

```bash
npm install

# .env.local 생성 후:
#   GEMINI_API_KEY=...

node scripts/verify-sources.js   # 소스 검증 재실행
```

RSS 주소와 robots.txt 정책은 바뀌므로 검증은 주기적으로 재실행할 것.

## 남은 리스크

**언론사 기사 저작권.** Gemini 약관 제약은 해소했으나, 타사 기사를 요약해 상업
서비스하는 행위 자체의 저작권 문제는 남아 있다. 완화책(짧은 요약 · 원문 링크 필수 ·
출처 명시)을 설계에 반영했으나 면책은 아니며, 실서비스 런칭 전 법률 자문이 필요하다.
